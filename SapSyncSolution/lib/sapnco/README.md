# SAP .NET Connector 3.1 binaries

Copy the **x64** SAP NCo 3.1 for .NET (Core / .NET 5+) binaries here:

- `sapnco.dll`
- `sapnco_utils.dll`

They are licensed by SAP, available from the SAP Support Portal (https://support.sap.com/nco), and are
intentionally excluded from source control. Alternatively build with `-p:SapNcoPath=<folder>`.
